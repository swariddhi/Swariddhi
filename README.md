# Artist Portfolio Template

A responsive, image-led artist/illustrator portfolio inspired by the layout in the reference screenshots. Built with plain HTML, CSS, and JavaScript so it can be hosted free on GitHub Pages.

## Preview locally
Open `index.html` in your browser. No build step or dependencies required.

## Personalize it
1. Change `Your Name`, `Your City`, and `hello@example.com` in `index.html`.
2. Replace the four SVG demo illustrations in `assets/` with your own artwork. Keep the filenames or update each image path in `index.html`.
3. Update the social URLs in the header.
4. Adjust colors, spacing, and fonts in `style.css`.

## Publish on GitHub Pages
1. Create a new GitHub repository, for example `artist-portfolio`.
2. Upload all files and folders from this template to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for the Pages deployment and open the URL GitHub provides.

No newsletter section or Squarespace branding is included.
